## 🚀 NEXUS-X Gaming PC Landing Page

A stunning, high-performance PC hardware showcase built with Next.js 14, TypeScript, and Tailwind CSS.

### 🎨 Features

- **Vivid Design**: Neon gradients, glassmorphism effects, and animated backgrounds
- **Responsive**: Fully responsive layout for desktop, tablet, and mobile
- **Modern Tech Stack**: Next.js App Router, TypeScript, Tailwind CSS
- **Interactive Components**: Smooth animations and hover effects
- **Performance Optimized**: Built with Next.js optimization in mind

### 📁 Project Structure

```
landing-page/
├── app/
│   ├── components/
│   │   ├── Hero.tsx          # Hero section with animated 3D product visual
│   │   ├── Features.tsx      # Product features with colorful icons
│   │   ├── Specifications.tsx # Detailed specs table
│   │   ├── CTA.tsx           # Call-to-action section
│   │   └── Footer.tsx        # Footer with links
│   ├── layout.tsx            # Root layout with metadata
│   ├── page.tsx              # Main landing page
│   └── globals.css           # Global styles with custom animations
├── .eslintrc.json
├── next.config.js
├── package.json
├── postcss.config.js
├── tailwind.config.ts
└── tsconfig.json
```

### 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom theme
- **Icons**: Lucide React
- **Fonts**: Inter (UI) & Roboto Mono (mono)

### 🚀 Getting Started

```bash
# Install dependencies (already done)
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

### 🌐 View the Page

Open your browser and navigate to:

```
http://localhost:3000
```

### 🎯 Key Features

1. **Hero Section**:
   - Animated background with mesh gradients
   - Glassmorphism statistics cards
   - 3D product visual using CSS-only gradients
   - Floating decorative elements

2. **Features Section**:
   - Color-coded feature cards (cyan, blue, purple, pink, green, orange)
   - Hover effects with scale and glow animations
   - Icon-based design with gradient backgrounds

3. **Specifications Table**:
   - Categorized sections (GPU, CPU, RAM, Storage, etc.)
   - Glass-panel design
   - Hover effects on data rows

4. **CTA Section**:
   - Three-tier pricing (Starter, Pro, Ultimate)
   - Most popular badge
   - Feature comparison
   - Warranty highlights

5. **Footer**:
   - Brand information
   - Product links
   - Support links
   - Newsletter subscription

### 🌟 Design Highlights

- **Glassmorphism**: Used throughout for modern, elegant look
- **Neon Gradients**: Animated gradients for highlights and backgrounds
- **Smooth Animations**: Fade-in, slide-in, float animations
- **Responsive Grid**: Mobile-first approach with media queries
- **Interactive Elements**: Hover states with scale, glow, and color changes

### 📱 Responsive Design

- **Desktop**: Full layout with sidebar navigation
- **Tablet**: Adjusted spacing and font sizes
- **Mobile**: Stacked layout with hamburger menu
